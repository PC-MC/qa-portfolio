# Test Case: Проверка восстановления пароля пользователя

## ID
TC-001

## Title
Проверка восстановления доступа через ссылку "Забыли пароль?"

## Priority
Medium

## Preconditions
Открыта страница входа пользователя.

## Test Data
Пользовательский аккаунт существует.

## Steps
1. Открыть страницу входа.
2. Нажать ссылку "Забыли пароль?".
3. Проверить открытие функциональности восстановления доступа.

## Expected Result
Открывается функциональность восстановления доступа пользователя.
