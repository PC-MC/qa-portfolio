# Тест-дизайн: таблица решений

## Функциональность

Применение промокода при оформлении заказа.

## Условия проверки

| Условие | Значения |
|---|---|
| Пользователь авторизован | Да / Нет |
| Сумма заказа | 5000 ₽ и больше / меньше 5000 ₽ |
| Промокод действительный | Да / Нет |

---

## Таблица решений

| Авторизация | Сумма заказа >= 5000 ₽ | Промокод действителен | Ожидаемый результат |
|---|---|---|---|
| Да | Да | Да | Скидка применяется |
| Да | Да | Нет | Отображается ошибка |
| Да | Нет | Да | Скидка не применяется |
| Нет | Да | Да | Требуется авторизация |
| Нет | Нет | Нет | Требуется авторизация |

---

## Применение в работе QA

Таблица решений помогает проверить комбинации условий и убедиться, что для каждого варианта система имеет правильное поведение.
