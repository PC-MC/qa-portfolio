# Тест-дизайн: классы эквивалентности и граничные значения

## Функциональность

Проверка поля пароля при регистрации и восстановлении пароля.

## Требование

Длина пароля:

- минимальное значение: 8 символов;
- максимальное значение: 20 символов.

---

## Классы эквивалентности (Equivalence Partitioning)

Разделение входных данных на группы, внутри которых система должна работать одинаково.

| Класс | Входные данные | Ожидаемый результат |
|---|---|---|
| Невалидные данные | Пароль менее 8 символов | Отображается ошибка |
| Валидные данные | Пароль от 8 до 20 символов | Пароль принимается |
| Невалидные данные | Пароль более 20 символов | Отображается ошибка |

---

## Граничные значения (Boundary Value Analysis)

Проверяем значения около границ допустимого диапазона.

| Значение | Ожидаемый результат |
|---|---|
| 7 символов | Ошибка |
| 8 символов | Успешное сохранение |
| 9 символов | Успешное сохранение |
| 19 символов | Успешное сохранение |
| 20 символов | Успешное сохранение |
| 21 символ | Ошибка |

---

## Применение в работе QA

Методы тест-дизайна позволяют уменьшить количество проверок, сохранив покрытие основных сценариев.

Используются при подготовке тест-кейсов и чек-листов.
