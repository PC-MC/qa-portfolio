## Project

## Story

### SCRUM-1 — Восстановление пароля пользователя

Описание:
Пользователь должен иметь возможность восстановить доступ к аккаунту через функцию восстановления пароля.


## Test Case

### SCRUM-4 — Проверка восстановления пароля пользователя

Выполнено:
- создана задача типа Task для проверки функциональности;
- описаны Preconditions;
- описаны Steps;
- описан Expected Result.


## Bug

### SCRUM-5 — Восстановление пароля не работает после перехода по ссылке "Забыли пароль?"

Environment:
Chrome, Windows 11

Preconditions:
Пользователь находится на странице входа.
Аккаунт пользователя существует.

Steps:
1. Открыть страницу входа.
2. Нажать ссылку "Забыли пароль?".
3. Выполнить восстановление пароля.
4. Попробовать войти с новым паролем.

Actual Result:
Пользователь не может войти с новым паролем.

Expected Result:
Пользователь успешно входит с новым паролем.

Severity:
Major

Priority:
High
