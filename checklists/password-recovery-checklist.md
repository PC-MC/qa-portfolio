# Checklist: Проверка восстановления пароля

## Password Recovery

- Проверить наличие ссылки "Забыли пароль?"
- Проверить доступность ссылки для пользователя
- Проверить переход на страницу восстановления пароля
- Проверить отображение формы восстановления пароля
- Проверить возможность ввода данных для восстановления
- Проверить успешное восстановление доступа
- Проверить возможность входа с новым паролем
- Проверить сообщение об ошибке при некорректных данных
