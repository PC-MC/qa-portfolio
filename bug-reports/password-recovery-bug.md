# Bug Report: Password Recovery

## Bug ID
BUG-001

## Title
Восстановление пароля не работает после перехода по ссылке "Забыли пароль?"

## Environment
Chrome, Windows 11

## Preconditions
Пользователь находится на странице входа.
Аккаунт пользователя существует.

## Steps to reproduce
1. Открыть страницу входа.
2. Нажать ссылку "Забыли пароль?".
3. Выполнить восстановление пароля.
4. Попробовать войти с новым паролем.

## Actual Result
Пользователь не может войти с новым паролем.

## Expected Result
Пользователь успешно входит с новым паролем после восстановления доступа.

## Severity
Major

## Priority
High
